Siguientes pasos

Esta sección asume que la Wii U carga Aroma y tiene la HB App Store en el menú de Wii U. Si aún no has modificado tu consola adecuadamente empieza por ahí.
Puedes abrir el Environment Loader si enciendes la consola y mantienes presionado X.
Puedes abrir el menú Boot Selector si enciendes la consola y mantienes presionado START ⊕︀.
Abres el menú de plugins de Aroma presionado L + Abajo + SELECT ⊝.

Aroma Updater

Usa la aplicación Aroma Updater para descargar plugins y módulos básicos.

  1. Abre Aroma Updater desde el menú de Wii U.
  2. Pulsa A para revisar si existen actualizaciones.
  3. Pulsa R para cambiar de página.
  4. Selecciona los plugins y módulos que quieres añadir:
    • Bloopair para poder sincronizar algunos controles de terceras compañías.
    • Inkay para conectar la consola a Pretendo Network.
    • FTPiiU Plugin para transferir archivos a la Wii U mediante una conexión FTP.
    • SDCafiine Plugin para aplicar *mods* a juegos de Wii U.
    • Screenshot Plugin para tomar capturas de pantalla (TV y GamePad).
    • SwipSwapMe para intercambiar la visualización y el audio entre la TV y el GamePad.
  5. Pulsa START ⊕︀ para descargar y luego pulsa A para confirmar.
  6. Pulsa A para reiniciar la consola.
El Bloopair permite sincronizar controles Bluetooth. La sincronización de los controles compatibles se hace usando la propia interfaz de la Wii U (botón SYNC de la consola).
Para poder jugar online usando Pretendo Network es obligatorio crear una nueva cuenta de usuario en la Wii U estando conectado a Pretendo Network. Al momento de crear la nueva cuenta de usuario también crea un Identificador de Pretendo Network (PNID), aunque textos de la Wii U pongan "Identificador de Nintendo Network (NNID)".

Las cuentas de usuario con un Identificador de Nintendo Network van a pedir la contraseña en cada oportunidad si la consola está conectada a Pretendo Network.

Las cuentas de usuario con un Identificador de Pretendo Network van a pedir la contraseña en cada oportunidad si la consola está conectada a Nintendo Network.

HB App Store

Usa la aplicación HB App Store para descargar aplicaciones y plugins.

  1. Abre HB App Store desde el menú de Wii U.
  2. Toca en Search, busca wupinstaller y selecciona WUP Installer GX2 (Aroma), de Fangal.
  3. Pulsa A para descargar.
  4. Espera a que la descarga e instalación termine.
  5. Busca savemii y selecciona SaveMii /ProcessMod, modificación de w3irDv.
  6. Pulsa A para descargar.
  7. Espera a que la descarga e instalación termine.
  8. Presiona el botón SELECT ⊝ para salir de HB App Store.
WUP Installer GX2 es para instalar las copias digitales de tus juegos.
SaveMii /ProcessMod es para gestionar los archivos de guardado de los juegos.

Copia de seguridad de OTP y SEEPROM

Estos archivos contienen las claves de cifrado exclusivas de tu Wii U. Aroma realiza copias de seguridad de estos archivos automáticamente. Sirven para recuperar archivos en almacenamientos en formato WFS (incluyendo la memoria interna de la consola).

Los archivos otp.bin y seeprom.bin se encuentran en la tarjeta SD (real o emulada), en la carpeta sd:/wiiu/backups/[SERIAL].

Haz una copia de estos archivos en un lugar seguro en tu PC o en servicios en la nube de Internet para no perderlos.

Módulo Sigpatches

Añade el módulo Sigpatches a Aroma para solucionar el mensaje: "No se puede usar este programa. El identificador de Nintendo Network que se usó para adquirirlo se ha borrado.", así como el error 199-9999.

Modifica el modo virtual Wii (vWii)

Para modificar el modo vWii, continúa con la sección Modificación de vWii.

Si unicamente instalas los juegos de Wii y de GameCube usando WUP Installer GX2 o NUSspli no es necesario modificar el modo vWii.
