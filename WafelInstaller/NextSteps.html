Aroma Updater

Usa la aplicación Aroma Updater para descargar plugins y módulos básicos.

  • Abre Aroma Updater desde el menú de Wii U.
  • Pulsa A para revisar si existen actualizaciones.
  • Pulsa R para cambiar de página.
  • Selecciona los plugins y módulos que quieres añadir:
    • Bloopair para poder sincronizar algunos controles de terceras compañías.
    • Inkay para conectar la consola a Pretendo Network.
    • FTPiiU Plugin para transferir archivos a la Wii U mediante una conexión FTP.
    • SDCafiine Plugin para aplicar *mods* a juegos de Wii U.
    • Screenshot Plugin para tomar capturas de pantalla (TV y GamePad).
    • SwipSwapMe para intercambiar la visualización y el audio entre la TV y el GamePad.
  • Pulsa START ⊕︀ para descargar y luego pulsa A para confirmar.
  • Pulsa A para reiniciar la consola.
El Bloopair permite sincronizar controles Bluetooth. La sincronización de los controles compatibles se hace usando la propia interfaz de la Wii U (botón SYNC de la consola).
Para poder jugar online usando Pretendo Network es obligatorio crear una nueva cuenta de usuario en la Wii U estando conectado a Pretendo Network. Al momento de crear la nueva cuenta de usuario también crea un Identificador de Pretendo Network (PNID), aunque textos de la Wii U pongan "Identificador de Nintendo Network (NNID)".

Las cuentas de usuario con un Identificador de Nintendo Network van a pedir la contraseña en cada oportunidad si la consola está conectada a Pretendo Network.

Las cuentas de usuario con un Identificador de Pretendo Network van a pedir la contraseña en cada oportunidad si la consola está conectada a Nintendo Network.

HB App Store

Usa la aplicación HB App Store para descargar aplicaciones y plugins.

  • Abre HB App Store desde el menú de Wii U.
  • Toca en Search, busca wupinstaller y selecciona WUP Installer GX2 (Aroma), de Fangal.
  • Pulsa A para descargar.
  • Espera a que la descarga e instalación termine.
  • Busca savemii y selecciona SaveMii /ProcessMod, modificación de w3irDv.
  • Pulsa A para descargar.
  • Espera a que la descarga e instalación termine.
  • Presiona el botón SELECT ⊝ para salir de HB App Store.

Módulo Sigpatches

Añade el módulo Sigpatches a Aroma para solucionar el mensaje: "No se puede usar este programa. El identificador de Nintendo Network que se usó para adquirirlo se ha borrado.", así como el error 199-9999.

Modifica el modo virtual Wii (vWii)

Para modificar el modo vWii, continúa con la sección Modificación de vWii.

Si unicamente instalas los juegos de Wii y de GameCube usando WUP Installer GX2 o NUSspli no es necesario modificar el modo vWii.
